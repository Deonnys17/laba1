\#  UniDone



UniDone — це застосунок для організації навчання та повсякденних завдань. Допомагає студентам керувати своїми справами, дедлайнами та підвищувати продуктивність.



\---



\##  Можливості



\*  Створення та редагування завдань

\*  Встановлення дедлайнів

\* Відмітка виконаних завдань

\* Організація навчальних предметів

\*  Зручний перегляд списку задач



\---



\##  Технології



Проєкт реалізований з використанням:



\* \*\*Python\*\*

\* \*\*Tkinter\*\* (графічний інтерфейс)

\* (опціонально) \*\*SQLite\*\* для збереження даних
